# 抖音助手

在抖音网页版整理关注作者、检查作品更新，并把需要的视频与图文保存到本地。

**当前版本：0.1.206 · Chrome Manifest V3 扩展 · 中文侧边栏界面**

[下载 v0.1.206 安装包](https://github.com/wowdahe/douyin-assistant/releases/download/v0.1.206/douyin-assistant-0.1.206.zip) · [所有发布版本](https://github.com/wowdahe/douyin-assistant/releases) · [提交问题](https://github.com/wowdahe/douyin-assistant/issues)

本仓库提供已经编译好的插件，下载后即可通过浏览器的“加载已解压的扩展程序”安装，无需安装 Node.js、运行 npm 或自行编译。

## 功能概览

| 功能 | 可以做什么 |
| --- | --- |
| 同步关注 | 从当前登录账号的关注列表读取作者信息，查看同步进度和日志 |
| 账号整理 | 按备注、昵称、抖音号搜索，设置分类、标签、每日必看及下载偏好 |
| 检查更新 | 批量检查作者作品，并查看新增作品与处理状态 |
| 作品下载 | 按作者保存视频；按设置下载图文图片及可获取的实况片段 |
| 喜欢与收藏 | 下载当前登录账号的喜欢作品，识别并选择收藏夹进行下载 |
| 页面单作品下载 | 在受支持的已关注作者作品页面发起单作品下载，侧边栏接收任务 |
| 分类与标签 | 集中维护分类和标签，通过批量整理页处理多个账号 |
| 账号组 | 根据个人简介中的 `@` 关联整理账号组，查看成员和关注状态 |
| 名单处理 | 读取 `cleared-authors.json`，预览匹配情况后将相应作者设为“不下载” |
| 取关与独立黑名单 | 按界面确认执行取关或本地名单管理，并保留处理信息 |
| 数据备份 | 导出、导入插件本地数据库；下载的媒体文件另行保存在本机 |

首页顶部有“指南”按钮，随时可查看同步账号、选择文件夹、选择下载作者这三个准备步骤。

## 安装

### 运行环境

- 推荐使用最新版桌面版 **Google Chrome**。
- 插件依赖侧边栏、Manifest V3、调试器和本地文件夹授权能力。Microsoft Edge 等 Chromium 浏览器的实际可用性取决于其 API 支持；当前发布以 Chrome 为主要使用环境。
- 不适用于手机浏览器、Safari、Firefox 或 Internet Explorer。
- 使用同步与下载功能前，需要在同一个浏览器用户配置中登录[抖音网页版](https://www.douyin.com/)。

### 下载并加载

1. 从本仓库 **Releases** 下载 `douyin-assistant-0.1.206.zip`；也可以点击仓库页面的 **Code → Download ZIP**。
2. **先解压**，把文件夹放到一个长期保留的位置，例如“文档/浏览器插件/抖音助手”。
3. 在 Chrome 地址栏输入 `chrome://extensions/`。
4. 打开页面右上角的“开发者模式”。
5. 点击“加载已解压的扩展程序”，选择**直接包含 `manifest.json` 的文件夹**。
6. 安装后点击浏览器工具栏的“扩展程序”按钮，将“抖音助手”固定到工具栏。
7. 打开抖音网页版，点击紫色的插件图标，打开侧边栏。

Chrome 加载的是磁盘上的这个文件夹，安装后请保留它。仓库 ZIP 解压后通常会多一层仓库名目录，选文件夹时以 `manifest.json` 的位置为准。

本仓库采用手动加载方式发布，没有 Chrome 应用商店自动安装或自动更新入口。

## 第一次使用

### 1. 同步关注账号

在“账号”页点击“同步关注”，或进入“批量任务 → 关注 → 同步备份”，点击“开始同步关注”。

插件会打开或复用抖音“我的”主页，进入关注列表，尝试切换为最近关注并逐步读取。同步结束后回到“账号”页查看结果。执行期间保留相关抖音标签页，尽量不要手动切换正在处理的页面。

### 2. 选择保存文件夹

进入“设置 → 下载路径”，点击“选择”，指定存放视频和图片的本地文件夹，并同意浏览器的读写授权。建议为媒体库使用单独的文件夹。

只整理关注账号时，可以暂时跳过下载目录设置。

### 3. 选择需要下载的作者

打开账号详情，把需要保存作品的作者设为“下载”。三个状态的含义是：

| 状态 | 含义 |
| --- | --- |
| 下载 | 纳入相应的作者下载任务 |
| 未设置 | 尚未明确选择，不等同于已开启下载 |
| 不下载 | 明确跳过该作者的批量下载 |

回到“批量任务 → 关注 → 作品下载”，核对界面显示的账号范围后启动任务。可先选择少量账号确认保存结果，再扩大处理范围。

## 日常操作

### 账号整理与筛选

- 首页支持搜索备注、昵称和抖音号；“筛选”中可按分类、标签、下载状态等条件缩小列表。
- 顶部三个指标可直接查看全部账号、已设为下载的账号和未设置账号。
- “重置全部”可清除搜索与筛选条件。
- “设置”里的第二个模块是“分类与标签”，提供管理入口和批量整理入口。
- 详情页保留快捷键提示；输入框内输入文字时不会触发普通账号快捷操作。

### 账号组是什么

账号组来自已采集的个人简介中的 `@` 关联。例如 A 的简介提到了 B，插件识别到关联后会把两者整理到同一组。可以在“设置 → 账号组”查看成员和关注状态；“重建账号组”使用已经采集的资料重新整理关联。

### 下载喜欢与收藏

进入“批量任务 → 喜欢与收藏”。“下载我的喜欢”使用当前登录账号的喜欢列表；收藏下载先识别收藏夹，再选择需要的收藏夹。页面可访问性、作品状态和登录状态会影响结果。

### 任务暂停与停止

支持暂停的任务会显示“暂停/继续”。部分停止操作需要等待当前账号或当前下载步骤结束，界面会显示“准备停止”或“停止中”；以任务提示为准。下载期间保持侧边栏和相关标签页打开，电脑尽量不要休眠。

设置中的“切换提示音”在开启时会试听，调节音量后按最终音量反馈；0% 为静音。

### 清空作者名单：为什么总数和修改数不同

“设置 → 清空作者名单”读取的是配套播放器生成的 `cleared-authors.json`，先预览，再确认操作。这里的“设置为不下载”只修改插件的下载偏好。

例如，文件有 100 条记录，其中只有 62 个账号能在当前插件数据库中通过 UID 或 SECUID 匹配；这 62 个账号中，如果 46 个已经是不下载，那么实际待修改的只有 16 个。其余 38 条未匹配记录不会被修改。插件不会仅凭相同昵称认定是同一个作者。

### 取关与独立黑名单

取关会实际改变抖音上的关注关系。详情页“拉黑”按当前确认框执行取关并移入插件的独立黑名单；批量整理中的“转移到黑名单”处理本地账号和作品记录。它们并不代表同一操作，执行前请以相应按钮的确认说明为准。插件的独立黑名单是本地管理功能。

## 文件保存与数据备份

### 本地文件结构

以下为典型布局，索引及子目录按实际任务生成：

```text
你选择的下载文件夹/
├── library.json                # 作者级媒体库索引
├── work-index.json             # 作品索引
├── 作者UID/
│   ├── works.json              # 作者作品与下载记录
│   ├── 作品ID.mp4
│   └── 图文作品/
│       ├── 作品ID_01.webp
│       └── 作品ID_01_live.mp4
├── 我的喜欢/
│   ├── works.json
│   └── …
└── 我的收藏/
    └── 收藏夹名称/
        ├── works.json
        └── …
```

图片的实际扩展名取决于获取到的媒体格式。已有下载记录、文件状态和索引会共同参与后续处理，不建议随意编辑索引 JSON。

### 备份与恢复

1. 进入“批量任务 → 关注 → 同步备份”。
2. 在“数据备份与恢复”区域点击“导出”，保存 JSON 备份。
3. 换浏览器、换电脑或重新安装前，先导出插件数据，并单独备份下载目录。
4. 恢复时选择“导入”，读取备份文件，再到设置中重新选择下载目录。

**导入会先清空当前插件数据库，再写入备份数据。** 请先导出当前数据。数据库备份不包含已经下载的视频、图片文件，也不能替代媒体文件备份。

导出的 JSON 包含账号和整理记录，分享前请检查其内容。

## 更新与卸载

### 更新到新版本

1. 停止正在运行的任务，导出一份插件数据备份。
2. 下载新版本并解压，将新版本完整文件替换到原来加载的插件目录。
3. 到 `chrome://extensions/` 找到“抖音助手”，点击“重新加载”。
4. 刷新已打开的抖音网页，关闭后重新打开插件侧边栏。
5. 查看账号页顶部的前台、后台版本号，确认都更新到了目标版本。

建议保持原安装路径并使用“重新加载”。删除扩展后再安装或改变解压加载路径，可能改变扩展身份并影响原数据库的访问；即使保持原路径，也建议先备份。升级若增加权限，浏览器可能要求重新确认。

### 卸载

在 `chrome://extensions/` 点击“移除”。卸载前导出需要保留的插件数据；本地下载目录由你自行管理，卸载插件不会替你删除其中的视频和图片。

## 权限与隐私

### 扩展权限的用途

| 权限 | 用途 |
| --- | --- |
| `activeTab` | 在用户操作时访问当前相关标签页 |
| `tabs` | 查找、打开、复用和切换执行任务所需的抖音标签页 |
| `sidePanel` | 显示插件侧边栏 |
| `scripting` | 在抖音页面执行读取资料、识别作品和页面操作脚本 |
| `debugger` | 使用浏览器调试协议观察页面网络响应、读取任务所需数据及执行相关页面操作；Chrome 可能显示调试提示条 |
| `storage` | 声明浏览器扩展存储能力；主要账号和作品记录使用本地 IndexedDB |

站点权限覆盖抖音网页版及 Manifest 中列出的抖音相关媒体域名，如 `douyinvod.com`、`douyinpic.com`、`byteimg.com`、`smtcdns.com` 等，用于读取作品与下载媒体。完整权限列表可查看本仓库的 [manifest.json](manifest.json)。

本地目录读写需要另行通过浏览器文件夹选择和授权完成。

### 数据如何保存

- 账号、作品记录、分类、标签和设置等保存在当前浏览器扩展的本地数据库中。
- 媒体文件写入你主动选择并授权的本地目录。
- 插件使用当前浏览器的抖音登录状态，与抖音网页及媒体服务交互；这些访问仍受平台自身的数据处理方式约束。
- 当前发行版本未配置开发者自建的数据上传或分析统计服务。
- 本插件无需单独注册账号，也不需要在插件内输入抖音密码。

## 常见问题

### 为什么安装时提示找不到 Manifest？

请先解压 ZIP，再选择直接包含 `manifest.json` 的文件夹。不要选择 ZIP 文件、它的上一级空目录或单独的 `assets/` 目录。

### 点击图标没有打开侧边栏？

确认扩展已启用，使用最新版桌面 Chrome，并打开一个正常的抖音网页。尝试重新加载扩展后刷新页面。浏览器自身设置页等受限制页面不适合执行插件任务。

### 提示前后台版本不同或 `unknown message type`？

这通常是部分页面还在使用旧代码。到扩展管理页“重新加载”，刷新抖音网页，再关闭并重新打开侧边栏；核对两个版本号。

### 同步不到账号，或者同步中断？

先确认当前浏览器已登录抖音，关注列表可以手动打开。验证码、登录过期、页面结构变化或网络异常都可能影响同步。检查同步日志，处理页面提示后再试；不要连续重复启动任务。

### 选择过下载目录，为什么又要求授权？

浏览器重启、权限失效、恢复备份或目录移动后可能需要重新授权。到设置中重新选择原下载目录，并允许读写。

### 为什么有些作品下载失败或数量与页面不同？

作品被删除、访问受限、媒体链接过期、网络错误、图文下载选项、重复记录及页面加载情况都可能影响结果。以任务日志中的具体原因和实际保存文件为准。插件不保证所有账号和所有类型作品都能完整获取。

### 能否关闭浏览器让它在后台继续下载？

不能。任务需要浏览器及相关页面保持运行，部分下载由侧边栏协调。关闭侧边栏、浏览器或电脑休眠都可能中断任务。

### 为什么下载目录里会有 `.part` 文件？

这是下载过程中的临时分块文件，正常完成后会处理为目标文件。发生中断时可能保留，用于受支持的续传流程；先结合任务日志确认状态。

### 是否包含播放器或小红书插件？

不包含。本仓库仅发布抖音 Chrome 扩展的编译结果。配套 Python 播放器和小红书插件属于独立项目，不是安装本插件的前置条件。
